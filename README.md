五岔路口交通信号灯配时设计
问题描述
路口共有 A、B、C、D、E 五条道路：
C 为单行道，只能驶出（车辆不能从 C 进入路口）
E 为单行道，只能驶入（车辆不能驶出到 E）
A、B、D 为双向道路
共有 13 条可通行路线，其中部分路线不能同时放行（如 E→B 与 A→D），
部分路线可以同时放行（如 A→B 与 E→C）。目标：设计一套信号灯配时方案。
建模思路
路线：把每条允许的通行方向表示为 (驶入口, 驶出口)，例如 A→B。
驶入口集合 = {A, B, D, E}，驶出口集合 = {A, B, D, C}，两者不相等，
一共得到 4×4−3 = 13 条路线，与题目一致。
冲突判断：把 5 条腿按图中方位顺时针排成一个圆（C, D, E, A, B）。
每条路线相当于圆周上连接"驶入口"和"驶出口"两点的一根弦。
两条路线冲突 ⇔ 两根弦在圆内交叉。共享起点（同一路口发散）、
共享终点（汇合）或首尾相接的路线视为不冲突，这与实际路口的几何
情况完全对应。
代码中用题目给出的两个例子做了自检：
E→B 与 A→D → 冲突（不能同时放行）✔
A→B 与 E→C → 不冲突（可以同时放行）✔
信号相位设计 = 图着色：13 条路线之间的冲突关系构成一张"冲突图"，
给路口设计信号灯，本质上就是给这张图着色——同一种颜色（同一相位）
内的路线两两不冲突，可同时放绿灯；相位数越少，路口通行效率越高。
本项目用回溯算法求出了最少相位数及一种最优分配方案。
运行结果
运行后得到：最少需要 5 个信号相位即可无冲突地放行全部 13 条路线，
每个相位包含的具体路线见程序输出（也可直接运行查看）。
文件说明
main.cpp：完整可执行代码，包含建模、冲突判断、
图着色求解相位方案、以及一个简单的信号灯运行演示（模拟每个相位
依次放行）。无需安装任何第三方库，直接用标准库运行。
运行方法
g++ -std=c++17 -O2 -o traffic_light_control main.cpp
./traffic_light_control
